O que é HTML


HTML (HyperText Markup Language) é uma linguagem de marcação usada para criar e estruturar o conteúdo de páginas da web.

Ela define elementos como títulos, parágrafos, imagens, links, listas, formulários, entre outros.

Importante: HTML não é linguagem de programação, pois não possui lógica, condições ou laços. Ele apenas marca e organiza o conteúdo.


De onde veio o HTML


O HTML surgiu no início da década de 1990, criado por Tim Berners-Lee, um cientista da computação que trabalhava no CERN (Organização Europeia para a Pesquisa Nuclear), na Suíça.

A ideia era simples:

➡️ facilitar o compartilhamento de documentos científicos entre pesquisadores de diferentes países.


Como o HTML surgiu


Tim Berners-Lee combinou duas ideias já existentes:


  • Hypertext (texto com links que levam a outros textos)
  • SGML (uma linguagem mais complexa de marcação)

A partir disso, ele criou:


  • o HTML
  • o HTTP
  • o primeiro navegador
  • o primeiro servidor web

Tudo isso deu origem à World Wide Web (WWW).


Quando o HTML surgiu


  • 1991 → primeira versão do HTML
  • 1995 → HTML 2.0 (primeira padronização oficial)
  • 1997–1999 → HTML 3.2 e HTML 4
  • 2014 → HTML5 (versão moderna)
  • Hoje → HTML5 continua sendo atualizado'

Para que serve o HTML


O HTML serve para:


  • Estruturar páginas da web
  • Organizar conteúdo (texto, imagens, vídeos)
  • Criar links entre páginas
  • Definir a base de qualquer site

Na prática:


  • HTML → estrutura
  • CSS → aparência
  • JavaScript → comportamento
  • Sem HTML, nenhuma página web existe 🌐
